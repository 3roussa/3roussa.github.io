# Portfolio d'Amin Driss

Ingénieur mécatronique et automatisme, diplômé de l'INSA Lyon.

Site statique publié avec GitHub Pages : projets (banc d'essai PowerTrain, convoi de véhicules emboîtables, robots du Club électrique ENIS, machines spéciales…), parcours et contact.

- `index.html` : accueil, liste des projets, parcours, contact
- `projet.html?p=…` : page d'un projet (contenu dans `data/projects.json`, images dans `images/`)
- `interface.html` : démo interactive de l'interface de supervision du banc
- `modeles-3d.html` : modèles 3D interactifs du robot de combat
